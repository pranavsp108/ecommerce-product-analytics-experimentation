# E-Commerce Product Analytics & Experimentation Platform

## Overview

This project simulates the work of a product data scientist at an e-commerce company. The goal is to identify opportunities to improve purchase conversion, customer retention, and revenue by analyzing event-level customer behavior, diagnosing funnel drop-offs, segmenting customers, modeling purchase propensity, and evaluating randomized marketing experiments.

The primary dataset is the Google Analytics 4 BigQuery E-Commerce Demo Dataset, which contains obfuscated event-level e-commerce data modeled after a real Google Analytics implementation. For the experimentation module, this project uses the MineThatData Email Campaign dataset to evaluate treatment effects, conversion lift, revenue lift, and segment-level campaign performance.

## Business Problem

Leadership wants to improve conversion, retention, and revenue. As a product data scientist, I analyze user behavior across the e-commerce journey to answer:

- Where do users drop off in the purchase funnel?
- Which traffic sources and devices drive high-quality customers?
- Which customer cohorts retain and generate revenue over time?
- Which users are most likely to purchase?
- Did the email campaign create incremental conversion or revenue lift?
- What product and marketing actions should leadership prioritize?
